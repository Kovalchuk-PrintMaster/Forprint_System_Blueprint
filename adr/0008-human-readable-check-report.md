# ADR 0008: Add Human-Readable Check Report

## Status

Accepted

## Context

Поточна команда `make check` добре підходить для технічної перевірки, але її звіт не завжди зручно читати людині. Для ForPrint System Blueprint важливо швидко бачити:

- що саме перевірялось;
- який був очікуваний результат;
- чи є проблема;
- чи є попередження;
- скільки часу зайняла перевірка;
- де лежить збережений звіт.

## Decision

Додати окрему команду:

```bash
make check-report

Вона запускає scripts/run_blueprint_checks.py, який формує:

кольорову terminal-таблицю;
JSON-звіт;
Markdown-звіт.
Consequences

Позитивні наслідки:

перевірки легше читати;
простіше пояснювати стан проєкту;
майбутній Project Inspector зможе використати подібний формат;
make check залишається простим технічним контролем.

Компроміси:

з’являється ще один службовий скрипт;
generated reports не комітяться, щоб не засмічувати репозиторій.
