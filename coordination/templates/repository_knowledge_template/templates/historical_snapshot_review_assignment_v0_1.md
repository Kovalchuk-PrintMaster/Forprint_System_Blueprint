# Historical Snapshot Review Assignment v0.1

Review a selected period of RCI, REDM and SDRS snapshots.

## Required questions

- Did declared goals remain stable?
- Which objectives progressed?
- Which objectives repeatedly stalled?
- Which blockers recurred?
- Which modules waited on dependencies?
- Where was work repeated?
- Which workstreams consumed attention with weak goal contribution?
- Which old implementations may be reusable?
- Which decisions changed direction and why?
- Which unknowns persisted?
- What new capability or module may be necessary?
- What should continue, accelerate, split, pause, stop-candidate or be reassessed?

## Safety

Do not treat snapshot age as proof of irrelevance.
Do not authorize deletion, stopping or new module creation automatically.
Separate evidence from recommendations.

## Output

Produce a dated review artifact with:

```text
period
snapshots_reviewed
stable_goals
direction_changes
progress
recurring_blockers
rework_signals
portfolio_balance
reuse_candidates
attention_recommendations
unknowns
evidence
```
