# ForPrint Automation Standards

This package defines the planned control surface for AI/module executors.

Documents:

1. `automation_operating_model_v0_1.md`
2. `module_executor_contract_v0_1.md`
3. `work_package_and_evidence_report_standard_v0_1.md`
4. `budget_runaway_and_progressive_activation_policy_v0_1.md`
5. `executor_performance_and_cost_metrics_standard_v0_1.md`
6. `automation_open_questions_v0_1.yaml`

These documents do not enable background autonomy. They define the rules that must exist before
broader automation is allowed.
