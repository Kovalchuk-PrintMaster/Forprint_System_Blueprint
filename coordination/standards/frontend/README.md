# ForPrint Frontend Standards

This standards group governs human-facing ForPrint web/UI implementation.

The mandatory foundation is:

`forprint_ui_design_system_and_frontend_consistency_standard_v0_1.md`

Any work package or prompt that creates or changes frontend/UI must include the current
frontend standard (or its successor) in authoritative context.

The group establishes:

- shared design tokens;
- reusable UI components;
- low-specificity/scoped CSS discipline;
- LIGHT/DARK theme support;
- COMPACT/STANDARD/LARGE interface presets;
- accessibility/reflow expectations;
- prohibition of page-local visual-language forks.

This group does not prescribe one JavaScript/CSS framework. The implementation stack may evolve
while the design-system contract remains stable.
