# ForPrint Project Constitution v0.1

**Canonical machine-readable authority:**  
`coordination/standards/governance/project_constitution_v0_1.yaml`

This Markdown file is a human-readable companion and is not a second authority source.

## Authority precedence

`Project Constitution -> Module Policy -> Execution Profile -> Work Front`

A lower layer may narrow authority. It may not widen authority unless a separate,
explicit authority-widening gate is approved and durable evidence is recorded.

## Project Laws

1. Canonical source authority outranks generated projections and views.
2. Accepted history is append-only and must not be rewritten in place.
3. Chat transcripts and conversational intent are not execution authority.
4. Existing canonical capability is evaluated before creating a competing NEW implementation.
5. Foreign-module or cross-repository mutation requires explicit authority.
6. Critical governed procedures produce durable evidence.
7. Required hard gates cannot be silently bypassed.
8. Breaking, subtractive, destructive, or authority-widening changes require an operator gate.
9. Raw conversation is evidence, not canonical authority.
10. Fresh assistants reconstruct state from accepted canonical sources, not chat memory.
11. Completion requires independent validation.
12. Autonomy is bounded by capability and blast radius.
13. Blueprint AI cannot modify and self-certify the same governing guardrail change.

## Module extension rule

Module Policy may add or tighten invariants. It cannot weaken a Project Constitution rule.

## Current CF-03 boundary

This constitution does not implement the CF-04 Work Front schema, CF-06 Execution
Profile registry, dispatcher launch, release authority, worker dispatch authority, or
automatic next-step activation.
