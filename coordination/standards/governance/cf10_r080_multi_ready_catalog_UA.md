# CF10 R080 — багатопровайдерний каталог без розширення повноважень

R080 прибирає обмеження **рівно одного** `READY` у живому Registry, залишаючи вимогу **щонайменше одного** придатного провайдера. Базовий default у `config/worker_runtime.yaml` лишається `github_copilot_cli` та `auto`; жоден новий провайдер не вмикається або не запускається автоматично.

Новий `cf10_r080_catalog_assignment_v0_1.py` формує суто кандидатний explicit per-attempt вибір поверх R079, прив'язаний до SHA256 повного каталогу, runtime config, вибраного descriptor і самого кандидата. Він **не** є заміною канонічного prepare/ACK/dispatch, не відбирає одноразовий claim і не записує ledger. Усі READY entries залишаються декларативними, а не дозволом на виконання.

R080 забезпечує сумісність з поточним Copilot Pilot, але **не відкриває** Codex/Claude runtime і не змінює перевірену модель systemd. Наступна окрема межа R081 — frozen source-bound вибір в prepare/dispatch та перехід на адаптерний інтерфейс із байтовою перевіркою сумісності Copilot. До її прийняття dispatch залишається Copilot-only.

Усі тести запускати через штатний Make. Каталог `tmp/` використовується виключно для доставки/одноразового staging; до runtime він не належить. Не чіпати Hestia, sudoers, a054 або історичні receipts.
