# Portfolio roadmap rebuild seeds

These files are **planning seeds**, not module execution roadmaps.

They preserve a common rebuild procedure for known modules after the 2026-08-25 operating-model
transition.

The current Blueprint Q-series roadmap is not replaced by these seeds.

For non-Blueprint modules, the seed says what must be reconciled before a new canonical delivery
roadmap can be trusted:

1. current evidence;
2. module identity;
3. Charter;
4. Capability Catalog;
5. target finish;
6. current implementation mapping;
7. full delivery roadmap;
8. end-to-end completeness review;
9. dependency timing;
10. weights/value/blocking;
11. baseline;
12. semantic review.

Do not hand these meta-seeds directly to module executors as business implementation work.
