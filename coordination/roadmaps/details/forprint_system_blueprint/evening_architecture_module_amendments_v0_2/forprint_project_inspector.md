# forprint_project_inspector — Evening Architecture Amendment v0.2

Status: Proposed mature-state expansion grounded in operator direction.

## Duplicate / semantic consistency audit

Find candidate equivalent functions/rules and compare common valid fixtures, edge cases, invalid inputs, rounding/precision, errors/logs, tests and ownership. Critical examples include price, accounting amounts, quantities and units.

Inspector reports evidence/consolidation candidates; it does not silently rewrite implementations.

## Dormant capability audit

Long-unused code/docs are review candidates, not automatic deletion. Consider usage, dependencies, owner, docs/tests, fallback purpose and roadmap relevance.

Use disposition candidates `KEEP / MOVE / MERGE / REWRITE / DEPRECATE / REMOVE / NEEDS_OWNER_REVIEW`.

## Misowned/orphan/stale instruction audit

Pay special attention to Calculator and Telegram historical responsibilities, stale agent/instruction files, parallel standards, orphan documents and current-vs-historical authority conflicts.

Support scheduled and risk-triggered audits with bounded findings, evidence, severity, owner and recommended disposition.
