# Blueprint External Input Contract

The live operator file is:

```text
operator_input/forprint_system_blueprint/bsa.yaml
```

The canonical template is generated by the self-audit script.

Do not hand-invent a replacement schema. Preserve:

```text
schema_version
module_id
workflow_id
request_id
status
source_bundle
analysis
```

Use `status: provided` only after the response has been filled.
