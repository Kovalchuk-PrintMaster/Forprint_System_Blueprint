## Non-negotiable interpretation rule

Never collapse these layers:

**Dialogue evidence → normalized historical item → current repository audit → accepted current authority → implementation verification.**

A historical report named PASS/READY, or a historical accepted design, is not proof of current implementation.

## Current-repository first step

Before executing any roadmap/prompt from this package:

1. open the live repository;
2. resolve current `coordination/releases/current.yaml`;
3. capture exact branch/HEAD/worktree state;
4. compare it with the `LAST_KNOWN_AUDIT_CONTEXT.yaml`;
5. update the current-audit backlog with verified/changed/superseded results.
