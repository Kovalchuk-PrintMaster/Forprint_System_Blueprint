# ForPrint Repository Knowledge & Direction — Blueprint Profile

This directory stores periodic, evidence-based memory for the Blueprint
repository and for the complete ForPrint portfolio.

The process is intentionally manual in v0.2. It is not a replacement for the
future Project Inspector.

## Blueprint streams

- `inventory/` — Repository Capability Inventory.
- `flows/` — Repository Execution & Dependency Map.
- `direction/blueprint_coordination/` — Blueprint tooling, standards,
  prompt/review workflow and automation.
- `direction/system_portfolio/` — whole-system goals, module balance,
  dependencies and decision rationale.

## Module distribution profile

The module profile is maintained separately at:

```text
coordination/templates/repository_knowledge_template/
```

It uses:

```text
direction/module_self_view/
```

The Blueprint-local profile must not use `module_self_view`.

## Authority

Snapshots are historical evidence. They do not override active global policy,
directives, module policy, approved prompts or canonical machine architecture.

Historical snapshots are never overwritten.
