# Portfolio Review History

Historical generated portfolio projections are retained here.

Rules:

- keep date/version in filename;
- never overwrite older PDF;
- preserve source representation when available;
- portfolio PDFs are internal review/history projections, not release authority;
- current rendering/content rules live in:
  `coordination/standards/governance/portfolio_rendering_and_content_specification_v0_1.md`.

The integration script for the 2026-08-31 review copies the operator-provided historical
portfolio PDFs from `tmp/` into this directory.
