# Blueprint Early Alignment Archive

## Status

Historical, non-authoritative evidence.

This archive preserves the early manual-alignment layer that previously occupied
current-looking locations such as top-level `human/`, several `machine/*.yaml` controls,
the old Prompt Dispatch index and the early project-landscape diagram.

The artifacts are preserved for provenance, ADR traceability and semantic review. They
must not be used to determine current Blueprint work or architecture when newer
authorities exist.

Current authority/navigation:

- release/work state → `coordination/releases/current.yaml`
- module identity → `machine/module_identity_registry.yaml`
- current architecture → curated current `machine/*.yaml`
- current prompts → Prompt Queue v0.2 module indexes
- current module repository locations →
  `coordination/module_sources/module_git_sources.yaml`
- current human architecture → `docs/architecture/`

`index.yaml` maps every original path to its archive path and preserves its pre-move
SHA-256.
