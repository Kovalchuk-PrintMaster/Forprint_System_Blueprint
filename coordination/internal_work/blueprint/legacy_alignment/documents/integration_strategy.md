# Integration Strategy

Початкова стратегія інтеграції — файлова і контрактна.

1. Blueprint описує модулі, об'єкти, контракти і потоки в YAML.
2. Скрипти генерують Mermaid-діаграми і module guides.
3. Кожен прикладний модуль у майбутньому має власний `forprint_module_manifest.yaml`.
4. Inspector порівнює manifest/status report модулів із Blueprint.
5. CRM пізніше показує підсумки Inspector у dashboard.

## Підключення нових модулів

Система має бути відкритою для майбутніх модулів: пакування, монтаж, зовнішня реклама, великі конструкції, нові канали доставки, нові типи виробництва.

Новий модуль має отримати:

1. `module_id` у `machine/modules.yaml`.
2. Межі відповідальності.
3. Дані, які він owns / consumes / provides.
4. Контракти інтеграції.
5. Потоки даних.
6. Impact rules.
7. Module guide.
