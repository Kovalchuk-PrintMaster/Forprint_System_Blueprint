2. Приклад із А1: як це має працювати практично
Клієнт пише:
“Мені треба роздрукувати А1”
і кидає PNG.
Ми беремо файл і робимо не “Photoshop-магію”, а дуже конкретний preflight.
Крок 1. Визначаємо ціль
А1 — це приблизно:
594 × 841 мм
Тут нам не треба Photoshop. Це просто довідник форматів.
Крок 2. Дивимось розмір PNG
Наприклад файл:
3000 × 3000 px
Це квадрат.
А1 має пропорцію:
841 / 594 ≈ 1.416
Файл має пропорцію:
3000 / 3000 = 1.0
Різниця велика. Значить автомат не має мовчки тягнути його в А1, бо буде або:
1. сильне обрізання;
2. великі білі поля;
3. сильна непропорційна деформація.
Тут система має повернути не “помилка”, а нормальний операторський висновок:
Файл квадратний, а потрібен формат А1.
Автоматично без погодження можна змінювати пропорції тільки до 5%.
Тут розбіжність значно більша.
Потрібне уточнення: обрізати, залишити поля, змінити формат або надати інший файл.
Це дуже добре лягає на Telegram Bot: він не має сам “думати художньо”, він просто отримує структурований результат і ставить клієнту уточнення.
Крок 3. Рахуємо effective DPI
Для А1:
594 мм = 23.39 inch
841 мм = 33.11 inch
Якщо файл 3000 × 3000 px, то effective DPI:
3000 / 23.39 ≈ 128 dpi
3000 / 33.11 ≈ 91 dpi
Тобто по DPI може бути умовно прийнятно для великоформатного друку, але по пропорції — ні.
І це важливо:
якість і пропорція — це дві різні перевірки.

7. Як організувати Windows Photoshop Station практично
Я б робила її не як “людина відкрила Photoshop”, а як локального виконавця.
На Unix:
/photoshop_jobs/inbox/job_001/
    input.png
    job.json
Windows-станція бачить цю папку через SMB/SFTP/sync.
На Windows:
Photoshop Station Agent:
    1. бачить новий job.json;
    2. відкриває файл у Photoshop;
    3. запускає потрібний Action або script;
    4. експортує PDF/PNG preview;
    5. пише result.json;
    6. кладе результат у outbox.
Результат:
/photoshop_jobs/outbox/job_001/
    output.pdf
    preview.png
    result.json
    log.txt
Головне:
Unix не залежить постійно від Windows.
Windows Station — це fallback/quality station, а не основний рушій для кожного PNG.
