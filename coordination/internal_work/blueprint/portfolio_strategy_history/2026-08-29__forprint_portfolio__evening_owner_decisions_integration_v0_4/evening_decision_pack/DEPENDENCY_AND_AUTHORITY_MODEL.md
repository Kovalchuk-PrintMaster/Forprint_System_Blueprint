# Working dependency / authority model

| Question | Primary interface/authority |
|---|---|
| What is this material called / canonical ID / alias? | Library |
| How much physically exists? | Warehouse capability (working candidate) |
| How much is available after reservations? | Operations Control Registry |
| What will this job cost / require / how long? | Calculator |
| Is a payment/accounting operation completed? | Accounting Registry Service |
| What is the physical delivery state? | Logistics |
| How should two modules communicate structurally? | Integration Gateway contract capability |
| What project standards must modules follow? | Blueprint |
| Is a module formally compliant with rules? | Project Inspector |
| Is a workstation/server technically healthy/configured? | System Administration |
| Is a backup restorable and retained correctly? | Cloud Backup Manager |
| Who is this user and what may they access? | Identity & Access Service |
| What is the customer relationship/contact/reliability context? | CRM |
| How do we communicate via Telegram/voice? | Channel Orchestrator |
| What active incidents/shortages/deadlines are open? | Operations Control Registry |
