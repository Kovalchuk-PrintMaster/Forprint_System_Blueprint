# Blueprint — evening delta

Blueprint is the analytical/architectural coordinator. It decides whether project direction is rational, whether module progress is balanced, whether standards are stale, and whether a better path exists.

Project Inspector only checks formalized rules and reports.

Required new capabilities:
- documentation freshness/revision control;
- machine-readable capability/index surface;
- roadmap completeness dashboard;
- step-level dependency/blocker table;
- SHORT/BALANCED/EXPANDED reporting modes;
- Unassigned Capability & Decision Queue.

Documentation, Make targets and capability indexes must be treated as maintained interfaces, not static files that can silently lag behind code.
