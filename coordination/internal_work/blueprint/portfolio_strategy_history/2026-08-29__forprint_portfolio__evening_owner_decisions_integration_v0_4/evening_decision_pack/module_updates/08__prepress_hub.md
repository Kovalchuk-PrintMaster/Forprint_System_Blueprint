# Prepress Hub — evening delta

Current sheet density is classified as SHORT — the minimum useful orientation level.

Core workflow:
client file -> automated preflight -> human-readable problem report -> client chooses self-fix or allowed auto-fix -> safe normalization/actions -> preview/layout -> confirmation -> Calculator/order flow.

Potential tools/capabilities include PitStop, Acrobat, Illustrator, Photoshop, internal scripts/actions.

Prepress defines required production tool profiles. System Administration installs, configures and verifies them.

Admin surface should configure file/image limits, service levels, paid/free processing, queue priority and customer exceptions.

Final limits should be based on real workstation benchmarks.

Prepress is not the long-term archive.
