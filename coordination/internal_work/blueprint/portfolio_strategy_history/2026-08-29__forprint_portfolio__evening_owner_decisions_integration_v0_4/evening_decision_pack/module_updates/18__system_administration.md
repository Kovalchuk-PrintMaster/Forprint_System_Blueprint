# System Administration — evening delta

Platform scope:
- server/module environments: Linux/Unix-like;
- desktop workstations: Windows;
- no separate macOS desktop support at this stage;
- Apple mobile belongs to iOS/mobile scope.

Core role:
OS, drivers, applications, versions/conflicts, updates/reinstall, plugins/scripts/actions/fonts, disk/storage health, server/workstation health, monitored directories, file-size policies, cleanup, profile standardization and drift detection.

Prepress says what a workstation class requires.
System Administration makes that state real and keeps it healthy.

Database-health candidate:
monitor central DB size, resources and suspicious storage patterns such as raw huge image blobs in transactional storage.
