# Blueprint Portfolio Strategy History

## Purpose

This directory preserves non-authoritative historical working snapshots that show
how ForPrint portfolio strategy, module Target States and synthetic roadmaps evolved
through owner review.

Typical artifacts include:

- printable module review packs;
- strategy discussion worksheets;
- cross-module target-state snapshots;
- intermediate portfolio roadmap review artifacts.

## Authority boundary

Artifacts here are historical working evidence.

They are **not** current roadmap, release, prompt, module-policy or standards authority.

Approved decisions discovered during review must be reconciled into the canonical
Module Charter / Capability Catalog / Target State / Roadmap / governance artifacts.

Historical snapshots are retained and never silently overwritten so that later
assistants can reconstruct how project strategy evolved over time.

## Naming

Use date-prefixed immutable names:

`YYYY-MM-DD__<scope>__<artifact>_vN_N.<ext>`

When a later review supersedes an earlier snapshot, keep both and record the
relationship in companion metadata rather than replacing the old artifact.
